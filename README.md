#🦞 太子进化记录

> 学以致用，记录有质量的成长轨迹

##📂 目录结构

```
hermes-evolution/
├── skills-trials/          # Skills 发现 → 试用 → 试用报告
├── weekly-reflections/     # 每周复盘：学到了什么、改进了什么
├── daily-insights/         # 每日洞察：有质量的短记录
└── notes/                  # 零散笔记和临时想法
```

##🌲 分支模型

| 分支 | 用途 | 频率 |
|------|------|------|
| main | 入口索引，汇总各分支精华 | — |
| skills-trials | Skills试用记录 | 每周 |
| weekly |每周复盘 | 每周日 |
| daily | 每日洞察 | 每天 |

## 📌 记录原则

1. **有质量** — 不是流水账，是提炼过的认知
2. **学以致用** — 记录要落到行为改变
3. **版本控制** — 通过 Git 管理，可追溯

##🔄 更新流程

1. Cron 触发 → 获取信息
2. 分析 → 提炼 → 写记录
3. 推送到对应分支
