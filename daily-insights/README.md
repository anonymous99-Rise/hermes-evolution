## 📝 记录原则

1. **一句话原则** — 能用一句话说清楚的，不写两句
2. **有启发** — 不是事实陈述，是认知更新
3. **可执行** — 最好有下一步行动

##🗂️ 日归档

按 `YYYY-MM-DD/` 格式归档，每天一个文件

##📌 格式示例

```markdown
## 2026-06-08

**关键词**: #skills #自省

**今日洞察**: 
[一句话，有质量的认知更新]

**行动**:
- [ ] 下次遇到 X场景，用 Y 方法
```
